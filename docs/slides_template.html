PinCite answers policy questions from CRS and GAO reports with quotes a person can verify in seconds.

The problem: the evidence exists, but finding and checking it takes more than an hour

Who: program-office (PMO) analysts at shipyards and Navy program offices, budget and policy analysts, Hill and agency staff, consultants.

Today: keyword-search congress.gov / gao.gov → open long PDFs → skim and Ctrl-F → copy the sentence → note the page → check it's the newest figure → format the citation. Repeat for every fact.

Chatbots are fast but can misquote or invent figures, and cite documents rather than pages, so analysts still re-check everything.

What is new

1 · Proof, not prose

Every fact is a verbatim quote with its PDF page, a link that opens the PDF at that page, and a screenshot with the quote highlighted. Checking a fact takes seconds.
2 · Honesty enforced in code

Code refuses any quote that doesn't match its page, and any number not in its quote. The reply is rebuilt from verified facts only. Answers say when they're partial.
3 · Plan first, then only as much AI as needed

The first agent picks what matters most (e.g. the SSBN, SSN, CVN, and DDG programs), plus the newest reports. One agent answers; the four-agent team joins only if fewer than 2 facts verify.

Safety: attacked on purpose, {{safety_pass}} checks passed

Invented facts: fabricated quotes, inflated numbers, and unverified citations are refused by code.

Prompt injection: a poisoned "CRS report" told the AI to claim a $9 trillion surplus. Even as the only report allowed, 0 findings repeated it.

Wrong actions: default-deny tools per agent, one-way delegation lanes, path traversal blocked.

Runaway spending: per-question token, request, page, and search caps. A 15,000-token budget stopped the team at {{budget_stop}} tokens (checked after each AI call).

Bugs found and fixed: "$500 billion" slipped past a digit-matching check; a headline with an unsupported year could end a run with no answer; parallel tool calls, or pages cached from another question, could get past the report limit; footnote numbers glued to sentences made faithful quotes fail. All fixed and re-tested.

What's next, and what doesn't work yet

With another month
  • Pilot: time 10 real questions with analysts
  • Read PDF tables (with page cites) and export to CSV
  • Smarter routing learned from past questions
  • GAO full text (GovInfo API), CBO, inspector-general reports, plus a flag when CRS and GAO disagree
  • Hosted version with nightly catalog refresh and alerts when a cited figure changes
Honest limits
  • Figures that live only in tables can be missed (first-of-class ship overruns: {{ship_status_short}})
  • "What matters most" comes from the model's own knowledge, matched to report titles
  • Results vary run to run; partial answers need human follow-up
  • Cache reuse across questions is best-effort at low traffic, and we couldn't share one cache across agents
  • GAO blocks automated downloads; its PDFs must be added by hand
